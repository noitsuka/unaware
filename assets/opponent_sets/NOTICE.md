These JSON catalogs contain public Pokémon movesets and sample-team parameter
data retrieved from Smogon University resources on 2026-10-01. Every catalog
records its own exact retrieval timestamp and format.

- Primary set source: https://www.smogon.com/dex/sv/
- Primary sample resource index: https://www.smogon.com/forums/threads/3777422/
- Sample and set mirror: https://pkmn.github.io/smogon/data/
- Mirror implementation/documentation: https://github.com/pkmn/smogon
- Ubers samples: the approved first post of
  https://www.smogon.com/forums/threads/3736089/ and its explicitly linked
  public Pokepastes; each paste URL remains in its corresponding catalog entry.

The mirror is a third-party project, not an official Smogon API. Sample authors
are retained where the mirror supplies them. A cache does not claim to be the
current metagame. These sets are coherent hypotheses for hidden opponent
builds, filtered by revealed information, without team recommendations.

Only published game parameters are included here. User exports, accounts,
ratings, battle records and passwords are not part of these catalogs and are
never uploaded by the opponent inference engine.
